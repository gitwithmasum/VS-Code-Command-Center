# Support

Thanks for using **Masum Galaxy // Developer OS**.

## Where to report issues

Use the GitHub issue tracker:

https://github.com/gitwithmasum/VS-Code-Command-Center/issues

## Include these details

When reporting a bug, include:

- Masum Galaxy // Developer OS version
- VS Code version
- Operating system
- Workspace/project type
- Steps to reproduce the problem
- Expected behavior
- Actual behavior
- Relevant error text from **Help → Toggle Developer Tools** or the Extension Host log

Please remove passwords, access tokens, API keys, private source code, and other secrets before sharing logs or screenshots.

## Feature requests

Feature requests are welcome through GitHub Issues. Describe the workflow you want to improve and why it would be useful.

## Privacy and safety

The extension is designed around local workspace analysis first. Actions that can modify code, create commits, push Git changes, create tags, or create GitHub releases retain explicit user-controlled confirmation gates.

Dependency audit and connected GitHub features can use network access when you explicitly invoke those workflows. Do not include secrets in issue reports.
